Adding a tool or doc page

This site is plain HTML/CSS/JS with no build step — every page is a real file you can open and edit directly.

Folder layout

yogurtlib-site/
├── docs-home.html              ← homepage / hub
├── assets/
│   └── style.css           ← shared colors, fonts, nav, footer
├── tools/
│   ├── custom-pather/
│   │   └── docs-home.html
│   └── data-visualizer/
│       └── docs-home.html
├── docs/
│   ├── docs-home.html
│   ├── getting-started.html
│   └── site-guide.html
└── CNAME                   ← yogurtlib.com (for GitHub Pages)

Adding a new tool

  • Create tools/<tool-name>/docs-home.html.
  • Link the shared stylesheet: <link rel="stylesheet" href="../../assets/style.css">.
  • Copy the header/footer markup from an existing tool page and add a link to your new tool in the nav on every page (home, other tools, docs).
  • Add a card for it on the homepage inside the .tool-grid.

Adding a doc page

  • Create docs/<page-name>.html, copying the layout from getting-started.html.
  • Link it from docs/docs-home.html's .doc-list.

Design tokens

Colors, fonts, and shared components (nav, footer, cards, buttons) live in assets/style.css as CSS variables under :root. Change a value there and it updates everywhere.

Deploying

Push to the main branch on GitHub with Pages enabled, or drag the folder into Netlify. See the README in the project root for the full deploy + domain setup steps.
